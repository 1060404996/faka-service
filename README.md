# 老王发卡服务系统

**作者 / 维护者：yu-ge（GitHub：[1060404996](https://github.com/1060404996)）**

一套**自用、可部署**的虚拟商品自动发卡服务：精美商城前台 + 功能完备的管理后台 + 支付宝官方接口对接，支付成功后**秒级自动发货**卡密。

## 功能特性

**商城前台（毛玻璃 / 极光动效 UI）**
- 商品分类浏览、关键词搜索、库存展示（支持实时数量 / 自定义文案两种模式）
- 商品卡片的悬浮光影、水波点击、渐变扫光等交互动效
- 收银台：支付宝二维码扫码 / 跳转支付，支付状态自动轮询
- 支付成功自动展示卡密，一键复制
- 订单卡密自助查询（凭订单号 + 下单联系方式）
- 客服面板：QQ 临时会话跳转 / 微信号复制 / 微信二维码扫码 / Telegram 跳转，留空渠道自动隐藏

**管理后台（同一套视觉体系）**
- 仪表盘：今日订单 / 营收 / 待补发 / 库存等实时统计
- 商品管理：增删改查、上下架、分类管理、自定义库存文案
- 卡密管理：批量导入（自动去重）、按商品筛选、批量删除、CSV 导出
- 订单管理：筛选搜索、详情查看、缺货补发、退款（自动退回卡密库存）、单删与批量删除
- 系统设置：分组折叠面板（站点信息 / 客服 / 支付宝对接 / 安全）、支付宝密钥配置、支付模式切换、管理员改密

**后端**
- Node.js + Express + SQLite（零外部数据库，单文件即数据）
- 支付宝官方开放平台接口：电脑网站支付（扫码/跳转）、手机网站支付（手机端体验最佳）、当面付扫码三模式
- RSA2 签名 / 异步通知验签 / 交易查询，金额与订单严格核验
- 事务化自动发卡，缺货自动标记待补发；重复支付幂等
- 管理端登录令牌（HMAC 签名 + 过期）、下单接口限流、全参数化 SQL

## 快速开始

环境要求：**Node.js ≥ 18**（推荐 20+）。

```bash
cd faka-service
npm install
npm start          # 启动后访问：
                   # 商城前台   http://localhost:3000/
                   # 管理后台   http://localhost:3000/admin.html
```

- 管理后台默认密码：**admin123**，登录后请在「系统设置 → 安全」中立即修改。
- 首次启动会自动生成演示分类、演示商品与演示卡密（带 `DEMO-` 前缀），便于直接体验完整流程。
- 默认处于**演示模式**（模拟支付）：商城下单后，在收银台点击「模拟支付成功」即可看到自动发货效果。

> 数据存放在 `data/faka.db`，备份该文件即可备份全部数据。删除该文件可重置系统。

### 宝塔面板 / 服务器一键部署

项目自带 `deploy.sh` 一键部署脚本，兼容宝塔面板服务器（CentOS 7+ / Ubuntu 20.04+ / Debian 11+），自动完成：检测并安装 Node ≥18 → 安装依赖（含 better-sqlite3 编译兜底）→ pm2 守护启动 → 开机自启 → 健康检查。

```bash
# 1. 把 faka-service 上传到服务器（如 /www/wwwroot/，勿传 node_modules/data）
# 2. 宝塔终端或 SSH 登录服务器，进入项目目录执行：
cd /www/wwwroot/faka-service
bash deploy.sh
# 或指定目录：bash deploy.sh /www/wwwroot/faka-service
```

执行完后按脚本末尾提示，在宝塔面板完成「绑定域名 + 反向代理 + SSL 证书 + 支付宝密钥配置」即可上线。

## 接入真实支付宝

支付宝官方接口需要**企业或个体工商户**资质（个人无法直接申请开放平台应用）。

### 准备

1. 注册并登录 [支付宝开放平台](https://open.alipay.com)，完成**企业 / 个体工商户**认证。
2. 创建「网页 / 移动应用」，获得 **AppID**。
3. 在产品中心开通支付产品，二选一（可都开通）：
   - **电脑网站支付**（`alipay.trade.page.pay`，页面跳转 + 扫码通用）
   - **手机网站支付**（`alipay.trade.wap.pay`，手机浏览器直接跳转支付宝，体验最佳）
   - **当面付**（`alipay.trade.precreate`，纯扫码，需开通当面付产品）
4. 配置 **RSA2 密钥**（开放平台工具 → 生成密钥或上传公钥）：
   - 应用私钥：自己保存，填入系统设置
   - 支付宝公钥：开放平台「查看支付宝公钥」中获取，填入系统设置
5. 在开放平台为应用配置：
   - **授权回调地址**（可选，用于支付后跳回）：`http(s)://你的域名/api/alipay/return`
   - **服务器异步通知地址**（必须，用于自动发卡）：`http(s)://你的域名/api/alipay/notify`
     （接口域名未备案 / 未配置 HTTPS 时，支付宝异步通知可能无法送达，请务必使用已备案的 HTTPS 域名）

### 配置步骤

1. 后台 →「系统设置 → 支付设置」
2. 支付模式切到 **正式模式**
3. 填写 AppID、应用私钥、支付宝公钥
4. 支付方式选择「电脑网站支付」「手机网站支付」或「当面付扫码」
5. 网关环境：线上用「正式环境」；调试先用「沙箱环境」+ 开放平台沙箱账号
6. 保存后，商城下单即为真实支付宝收款

### 测试建议

- 先在**沙箱环境**跑通：开放平台「沙箱」页面获取沙箱 AppID、沙箱买家账号，配合沙箱支付宝 App 完成一笔真实流程测试。
- 确认异步通知能收到（后台订单状态自动变为已支付并发货）后，再切换正式环境。

## 部署建议

- **HTTPS**：支付接口与验签依赖域名与回调，生产环境务必配置 HTTPS（Nginx/Caddy 反代均可）。
- **反向代理**：将 `/` 反代到本服务端口；如启用 HTTPS 终止，需把 `X-Forwarded-Proto` 传给后端（本服务已支持读取该请求头拼接回调地址）。
- **进程守护**：可用 `pm2 start server.js --name faka` 常驻。
- **改端口**：`PORT=8080 npm start`。

## 安全注意事项

1. **第一时间修改默认管理员密码**。
2. 应用私钥仅保存在自己的服务器配置中，切勿外泄；泄露后请在开放平台重置密钥。
3. 管理后台接口已做登录鉴权，请勿将后台地址暴露到公网之外的必要范围；可另加一层 IP 白名单 / 访问密码。
4. 保持 Node 与依赖更新，及时跟进安全补丁。
5. 定期备份 `data/faka.db`。

## 常见问题

| 问题 | 处理 |
|---|---|
| 支付后未自动发货 | 检查异步通知地址是否公网可达（HTTPS、备案）；在后台「订单管理」确认订单状态；若为缺货订单可点击「补发」 |
| 二维码生成失败 / 报错 | 演示模式无需二维码；正式模式请检查支付宝配置是否完整、网关环境是否与密钥匹配 |
| 后台登录提示过期 | 令牌有效期 7 天，重新登录即可 |
| 修改了站点名称不生效 | 保存设置后刷新前台页面 |
| 删除商品提示不允许 | 商品已有售出卡密时不允许删除（防止数据关联丢失），请先下架 |
| 支付宝报「验签失败 / 签名错误」 | 多为公钥/私钥填反或复制不全（含 `-----BEGIN/END-----` 头尾），或网关环境与密钥环境不一致 |
